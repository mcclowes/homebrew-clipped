# Clipped Homebrew tap

Install [Clipped](https://github.com/mcclowes/clipped), a native macOS clipboard manager, with Homebrew.

Requires **Apple Silicon** and **macOS 15 (Sequoia) or later**.

## Install

```sh
brew install --cask mcclowes/clipped/clipped
```

Launch Clipped from Applications after installation.

## Upgrade

```sh
brew update
brew upgrade --cask mcclowes/clipped/clipped
```

## Uninstall

```sh
brew uninstall --cask mcclowes/clipped/clipped
```

Report installation problems in [this tap's issues](https://github.com/mcclowes/homebrew-clipped/issues). Report app problems in [Clipped's issues](https://github.com/mcclowes/clipped/issues).
